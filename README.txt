AVINASH B N — ADAS & AUTOMOTIVE DATA PORTFOLIO

CONTENTS
- index.html: responsive portfolio website
- avinash-profile.jpeg: profile photo
- Avinash_BN_Resume.pdf: résumé download linked from the website

PREVIEW LOCALLY
1. Extract the ZIP (if needed).
2. Keep all three files in the same folder.
3. Double-click index.html to open it in Chrome, Edge, Firefox or Safari.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com/ and create a new public repository named avinash-portfolio.
2. Upload index.html, avinash-profile.jpeg and Avinash_BN_Resume.pdf to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub finishes publishing, your free site address will be:
   https://YOUR-GITHUB-USERNAME.github.io/avinash-portfolio/
   Replace YOUR-GITHUB-USERNAME with your GitHub username.

ALTERNATIVE: NETLIFY DROP
Visit https://app.netlify.com/drop and drag the extracted folder onto the page. Netlify will provide a free public URL.

EDITING
Edit index.html to update copy, sections, links or styling. Keep the image and PDF filenames unchanged unless you also update their references in index.html.

NOTES
- The site is responsive for phones, tablets and desktops.
- Animations respect the visitor's reduced-motion accessibility setting.
- Google Fonts are loaded online; the website itself is a static site and needs no build step.
- Review all résumé details and contact information before making the site public.
